Risk framework and data quality

Strategic Vulnerability Score = 0.40 x import dependence + 0.35 x (mining HHI / 100) + 0.25 x refining leader share
All inputs normalised to a 0 to 100 scale before weighting. The score is not computed for any mineral.

The gate is that all three inputs must exist and be complete. No mineral clears it. Publishing a weighted number on a proxy and a partial list would present an assumption as a measurement.
